## 1. Пробивной инструмент: дерево по типу инструмента, система станка на третьем уровне

**Было.** Ветка `/catalog/punchtools/` повторяла иерархию заказчика от 14.09: пять узлов второго уровня
(Thick Turret, Инструмент Trumpf, Murata/Salvagnini/Thin Turret, Формовочный, Роликовый) и внутри них
разделы по сериям и типам вперемешку, как на старом сайте.

**Стало.** 25 страниц. Корень `/catalog/punchtools/` (адрес сохраняем). Уровень 2 это тип инструмента:
Пуансоны `puansony/`, Матрицы `matritsy/`, Съемники `semniki/`, Кластеры (мультитул) `klastery/`,
Формовочный инструмент `formovochnyy/`, Направляющие `napravlyayushchie/`, Комплектующие и вспомогательный
инструмент `komplektuyushchie/`. Уровень 3 это система станка: `thick-turret/`, `trumpf/`,
`prochie-sistemy/` (у направляющих Trumpf нет, у комплектующих деления по системам нет).
Итого 1 + 7 + 17 = 25 страниц, все на листах «Структура сайта» и «Каталог», источник
«иерархия заказчика 21.09.2026 (Костя)».

Третий уровень файла заказчика (серии E80, TOP-90, FULLY GUIDED, 114, VULCAN, формы, операции формовки,
типы комплектующих, «по эскизу») страницами не становится: это значения фильтров, как заказчик и записал
в блоке ФИЛЬТРЫ. На листе «Фильтры каталога» 144 строки пробивного: 61 значение по свойствам
«Серия», «Форма», «Операция», «Тип комплектующей», «Наличие» плюс сами свойства
(Станция, Серия, Форма, Покрытие, Наличие, Зазор, Операция, Тип комплектующей, Система станка).
Счётчики пустые: фида пробивного нет, вопрос 36.

**Цена решения.** 17 страниц третьего уровня новые, адресов на старом сайте у них нет. 22 старых раздела
пробивного уходят 301, 3 брендовых адреса сохраняются. 300 карточек пробивного меняют раздел, из них
128 из смешанных серийных разделов встают на страницы входа по системе, а не в тип: разнести их по типам
можно только по разметке в 1С, это вопрос 35.

`/catalog/punchtools/murata_salvagnini_thin_turret/` остаются живыми адресами (URL сохраняем) и работают
как страницы входа по системе: список семи типов с отбором по этой системе, по образцу входа по бренду
в расходке лазера. В дереве типов они не узлы, на карте отдельная плашка «Вход по системе».
Решение под вопросом 33: альтернатива 301 на корень пробивного, но тогда теряется ссылочная масса
и пропадает цель для 301 смешанных серийных разделов.
