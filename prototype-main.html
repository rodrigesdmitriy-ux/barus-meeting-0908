Главная barus.tools — схема из штатных блоков INTEC.Prom

Принцип: ничего не разрабатываем. Берём только готовые блоки шаблона INTEC.Prom (панель «Точная настройка» → «Блоки главной страницы», демо promcrm.ru) и выбираем для каждого штатный вариант. Превью — реальные картинки вариантов из панели шаблона.

Всего в шаблоне 28 типов блоков главной, 149 вариантов оформления + 19 шапок + 6 футеров. Ниже — 16 блоков, которые собираем в главную, и 12, которые выключаем.

Блоки главной INTEC.Prom, которые выключаем (12 из 28)

  • Отзывы к товарам — нет массовых отзывов B2B
  • Готовые образы — fashion‑блок, не про инструмент
  • Коллекции — дублирует «Разделы»
  • Товар дня — нет акционной модели продаж
  • Истории (stories) — не для B2B
  • Статьи — сливаем с «Новости»; статьи — в разделе /articles/
  • Акции — включим, когда появятся; пока пусто
  • Команда — на странице «О компании»
  • Сертификаты — на странице «О компании»/«Сертификаты»
  • Видео / Видеогалерея / Фотогалерея — пока нет контента
  • Тарифы — не подходит модели
  • ВКонтакте — виджет ленты; при желании в футер
