3. Общие настройки шаблона (вкладка «Точная настройка»)

Общие

  • Цветовая схема: teal. Если есть поле своего цвета — #42c1c7.
  • Ширина сайта: Широкий (1400 px), контент — 1200 px.
  • Шрифт заголовков: Russo One (Google Fonts). Шрифт текста: Montserrat.
  • Тема: светлая. Тёмный — только футер и полоса «О компании».
  • Кнопки: фон #42c1c7, текст тёмный #232323. Белый текст на #42c1c7 даёт контраст 2.2:1 — не читается; тёмный даёт 7.3:1. Если шаблон не даёт менять цвет текста кнопки — в CSS-правках: .intec-button {color:#232323}.
  • Ссылки в тексте: #232323 с подчёркиванием, при наведении #42c1c7. Бирюзовым мелкий текст не пишем (та же причина).
  • Радиус скругления: 4 px (брендбук — прямые формы, полное скругление не используем).

Шапка

  • Шаблон: Тип 1. Меню: выпадающее с картинками. Фиксировать при прокрутке: да.
  • Слева логотип горизонтальный. Строка контактов: телефон СПб, «Заказать звонок», e-mail. Иконки: избранное, сравнение, корзина, вход.
  • Меню верхнее: Каталог · Услуги · Бренды · О компании · Проекты · Новости · Контакты.
  • Поиск: всплывающий, с подсказкой товаров.

Каталог

  • Корень: Плитка 1. Разделы: Тип 2, плитки 4 колонки, фото с белым фоном (предметная съёмка).
  • Фильтр: вертикальный 1, слева. Быстрый просмотр: Шаблон 2.
  • Карточка: Шаблон 4. Обязательно: наличие, ссылка «Скачать чертёж/каталог PDF», блок «Сопутствующие».

Услуги

  • Корень 5, разделы 5, элементы 11, карточка Широкая 1, баннер Тип 2.

Футер

  • Тип 1, тема тёмная (#232323). Блок над футером: Форма широкая 1 («Не нашли инструмент — пришлите чертёж»).
  • Слева логотип и контакты, «Обратный звонок», соцсети (VK, Telegram, YouTube). Справа колонки: Каталог · Услуги · Компания · Покупателям.
  • Нижняя полоса: логотип вертикальный белый, «© Барус Инструмент, 2000–2026», политика, ИНН.

Мобильная версия

  • Шапка Тип 1, меню — плитки с картинками. Шрифт заголовков 22 px, не меньше — Russo One на маленьких кеглях расползается.

5. План реализации

Этап 1 — общие настройки (1 день, Андрей)

  1. Цветовая схема, ширина, шрифты, кнопки, скругление — по разделу 3.
  2. Шапка Тип 1, футер Тип 1, форма над футером.
  3. Загрузить логотипы (горизонтальный в шапку, вертикальный в футер), favicon 32/180/512, цвет темы #232323.
  4. Проверить контраст кнопок; при необходимости CSS-правка.

Этап 2 — каталог и карточка (1–2 дня, Андрей + Екатерина)

  1. Корень, разделы, фильтр, быстрый просмотр — по разделу 3.
  2. Карточка Шаблон 4; включить SKU, чертёж PDF, сопутствующие.
  3. Фото категорий (8 шт.) под меню и плитки — от Екатерины, 800×600, белый фон.

Этап 3 — главная (2 дня, Андрей + Екатерина + Дмитрий на тексты)

  1. Собрать блоки в порядке раздела 4.
  2. Баннеры 3 шт. 1400×500 с тёмной подложкой под текстом — Екатерина по макету из prototype-main-v2.html.
  3. Тексты: слоганы баннеров, 4 преимущества, «О компании», 5 вопросов — Дмитрий.
  4. Наполнить проекты (3), отзывы (3), новости (3), отрасли (8 иконок).

Этап 4 — приёмка (0,5 дня)

  1. Проверка на 1400 / 1200 / 768 / 375.
  2. Проверка контрастов и шрифтов по брендбуку.
  3. Утверждение с Дмитрием, передача ТЗ Екатерине на остальные баннеры.
